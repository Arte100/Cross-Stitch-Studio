# Fonts used by the lettering tool

These font files are used by "Add lettering" to turn typed text into stitches. They are the original files from their authors and have not been changed.

| File | Font | Copyright |
|---|---|---|
| `Inter-SemiBold.otf` | Inter, version 4.000 | Copyright 2016 The Inter Project Authors |
| `Poppins-Medium.ttf`, `Poppins-Bold.ttf` | Poppins, version 4.004 | Copyright 2020 The Poppins Project Authors |
| `Lora-Variable.ttf`, `Lora-Italic-Variable.ttf` | Lora, version 3.008 | Copyright 2011 The Lora Project Authors, with Reserved Font Name "Lora" |

All of them are licensed under the SIL Open Font License, Version 1.1. The full text is in `OFL.txt` in this folder.

In short, that licence lets anyone use, copy and share the fonts free of charge, including with software and for commercial work, as long as the fonts are not sold on their own and this licence stays with them. It does not apply to documents or patterns made with the fonts.

The fonts keep their own licence. The GNU General Public License that covers the rest of this project does not apply to the files in this folder.

The "Classic stitch" alphabets are not font files. They were drawn for this project and are part of the app itself.
