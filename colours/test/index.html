Good to know

A match is the closest colour in the other brand. It is a guide, not an exact copy, because every maker dyes its own shades.

Where the colours come from. DMC colours were measured by us from real thread on our own DMC colour card. Madeira colours are read from Madeira’s own printed colour card. Anchor and Cosmo colours are read from published colour charts and pictures, so they are less exact. Sullivans has no colours yet, so each pair is shown in its DMC colour. Screens differ, so check against real thread where you can.

Where the matches come from. Madeira and Sullivans: each maker’s own conversion chart. Anchor and Cosmo: several published conversion charts, cross-checked against each other. Where charts differ, the other numbers are listed as “Also suggested”. Published charts contain slips, so we check every match against the colours above and leave out any that are clearly the wrong colour. Where that leaves a colour with no published match, we suggest the closest thread by colour and say so. Where a published match looks clearly off by colour, we keep it and name the thread that looks closer.

This is an independent guide. The Jolly Makery is not connected to any thread maker, and the brand names belong to their owners.
